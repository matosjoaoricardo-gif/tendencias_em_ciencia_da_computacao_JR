# Chatbot Especialista — Minha_IA

Chatbot que responde perguntas **apenas com base no conteúdo de uma página da Wikipédia** (por padrão, o artigo sobre Inteligência Artificial). Ele usa o modelo **Llama 3.3 70B** pela API da **Groq**, com o **LangChain**.

> **Desenvolvido no Google Colab.** O código foi escrito e testado em um notebook do Google Colab, e as instruções abaixo partem desse ambiente.

## Como funciona

1. O programa baixa o texto da página da Wikipédia com `WebBaseLoader`.
2. O texto é limitado aos primeiros 4000 caracteres, para não enviar um conteúdo grande demais ao modelo.
3. A cada pergunta, o programa monta um prompt com a persona, o texto da página e a pergunta, e o envia ao modelo.
4. O modelo responde usando só esse conteúdo. Se a resposta não estiver no texto, ele diz que não encontrou a informação.

Cada pergunta é independente: o chatbot **não guarda o histórico** da conversa.

## Personalização

- **Outra página:** troque o valor de `url` pelo endereço de outro artigo.
- **Mais conteúdo:** aumente o limite em `texto[:4000]`. Textos maiores gastam mais tokens e podem passar do limite do modelo.
- **Comportamento do bot:** edite o texto de `PERSONA`.
- **Criatividade das respostas:** altere `temperature` (valores baixos, como 0,3, dão respostas mais objetivas).
- **Modelo:** mude `model_name` para outro modelo disponível na Groq.

## Limitações conhecidas

- Só os primeiros 4000 caracteres da página são usados, então perguntas sobre partes mais adiante no artigo podem ficar sem resposta.
- Não há memória de conversa: perguntas como "e sobre isso?" não funcionam.
- O bot só responde com base na página carregada, por desenho.
- Falhas de rede ou limite de uso da API aparecem como mensagem de erro, mas o programa continua rodando.

## Como funciona

1. `ChatGroq` cria o cliente do modelo `llama-3.3-70b-versatile`.
2. A função `resposta_bot(mensagens)` monta a lista de mensagens: o prompt de sistema seguido do histórico da conversa.
3. `ChatPromptTemplate` transforma essa lista em um prompt, que é ligado ao modelo por uma *chain* (`template | chat`).
4. A resposta do modelo é adicionada ao histórico como `assistant`, e o ciclo se repete a cada pergunta.

## Limitações conhecidas

- O histórico existe só durante a execução. Ao fechar o programa, a conversa é perdida.
- O histórico cresce a cada turno. Em conversas muito longas, pode ultrapassar o limite de contexto do modelo.
- Mensagens do usuário com chaves `{` `}` podem causar erro no `ChatPromptTemplate`, que as interpreta como variáveis do modelo de prompt.
- Sem tratamento de erros: falhas de rede ou limite de uso da API encerram o programa.
